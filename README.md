# Exercise and Nutrition Agent

## Installation

**Requirements:** Windows 10/11, [Python](https://www.python.org/downloads/), [Node.js](https://nodejs.org/), and an internet connection.

### Step 1: Download

1. Click the green **Code** button on GitHub.
2. Select **Download ZIP**.
3. Extract the ZIP file.

### Step 2: Install

1. Open the extracted project folder.
2. Double-click `install.bat`.
3. Wait for installation to finish.

### Step 3: Run

1. Double-click `start.bat`.
2. Keep both command prompt windows open.
3. Open **http://localhost:5173** in your browser.

## Notes

- The Gemini API key is already configured for the instructor's evaluation copy.
- An internet connection is required for AI features.
- To stop the application, close both command prompt windows.
